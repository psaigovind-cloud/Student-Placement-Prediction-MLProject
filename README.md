# 🎓 Student Placement Prediction using Machine Learning

This is an end-to-end **Machine Learning project** that predicts whether a student will be placed or not based on academic and employability data.

---

## 🧠 About the Project

This project was completed by **Anirudh K** as part of a **10-mark Machine Learning assignment** and to build my **GitHub portfolio**.

The model analyses student records (CGPA, test scores, work experience, etc.) and predicts placement chances using a **Random Forest Classifier**.

---

## 🧩 Dataset

Dataset Source: [Kaggle - Factors Affecting Campus Placement](https://www.kaggle.com/datasets/benroshan/factors-affecting-campus-placement)

---

## ⚙️ Technologies Used

- Python 🐍  
- Pandas & NumPy  
- Matplotlib & Seaborn  
- Scikit-Learn (RandomForestClassifier)

---

## 🚀 Project Steps

1. Load and clean dataset  
2. Visualize trends (CGPA, employability scores, placements)  
3. Encode categorical features  
4. Train the Random Forest model  
5. Evaluate using accuracy & confusion matrix  
6. Visualize feature importance

---

## 📊 Results

- **Accuracy:** ~85–90%  
- **Key Factors:** CGPA, test scores, work experience
